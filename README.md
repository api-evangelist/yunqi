Yunqi (云器科技, English brands ClickZetta and Singdata) is a cloud-native AI Lakehouse company that unifies structured, semi-structured, and unstructured data on Apache Iceberg behind a single vectorized SQL engine. Its proprietary Generic Incremental Computation (GIC) model powers Dynamic Table pipelines, compute-storage separation, and native AI capabilities such as vector search, LLM functions, and Semantic Views. The platform is consumed programmatically through JDBC, an official Python connector (PEP 249), a Java SDK, the ZettaPark DataFrame API, a dbt adapter, a SQLAlchemy dialect, a Go client, and an AI-agent-friendly CLI, delivered as a fully managed SaaS on Alibaba Cloud, Tencent Cloud, and AWS. Backed by Qiming Venture Partners.
